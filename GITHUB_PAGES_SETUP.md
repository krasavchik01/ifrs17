# 🚀 Настройка GitHub Pages для Actuary Cloud KZ Demo

## Почему GitHub Pages?

HTMLPreview не может выполнять большие JavaScript файлы. GitHub Pages - это бесплатный хостинг от GitHub, который отлично работает с нашим демо.

## 📋 Инструкция по активации (3 минуты)

### Шаг 1: Откройте настройки репозитория

1. Перейдите на: https://github.com/krasavchik01/ifrs17
2. Нажмите на вкладку **Settings** (Настройки) вверху
3. В левом меню найдите раздел **Pages**

### Шаг 2: Настройте источник

В разделе **Build and deployment**:

1. **Source** (Источник): выберите **"Deploy from a branch"**
2. **Branch** (Ветка): выберите **`claude/ifrs17-automation-system-011CUz9Pz2hbCnzEDMfBQeCr`**
3. **Folder** (Папка): выберите **`/ (root)`**
4. Нажмите кнопку **Save** (Сохранить)

### Шаг 3: Дождитесь деплоя

- GitHub начнет процесс деплоя (займет 1-2 минуты)
- Вы увидите сообщение: "Your site is live at..."
- Ссылка будет: `https://krasavchik01.github.io/ifrs17/`

## 🔧 Если что-то не работает:

1. **Подождите 2-3 минуты** после активации Pages
2. **Очистите кэш браузера** (Ctrl+Shift+Delete)
3. **Откройте в режиме инкогнито** (Ctrl+Shift+N)
4. **Проверьте статус деплоя** в разделе Actions на GitHub
